# agentic-os

Agentic OS Edge: a private, self-hosted agentic operating system for small
and mid-sized companies. Assistants plan, research, draft and act across
Gmail, Calendar, GitHub and the web, with company data kept on company
hardware and every external effect gated by explicit authority.
